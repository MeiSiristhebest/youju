# Security Policy

## Supported Versions
Only the latest release on the `main` branch is actively supported with security patches.

## Reporting a Vulnerability
If you discover a potential security vulnerability, **please DO NOT create a public issue**.

Instead, please send a report directly to **`maox_neta@foxmail.com`** with:
- A description of the vulnerability
- Steps to reproduce or proof-of-concept
- Potential impact

We will respond promptly and coordinate a security fix and advisory release.
